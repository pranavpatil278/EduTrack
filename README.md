# 🎓 EduTrack

A web-based **Student Management System** developed using **Python** and **Flask**. This application provides an efficient way to manage student records and attendance through a simple, responsive, and user-friendly interface.


## ✨ Features

- 🔐 Admin Login Authentication
- 👨‍🎓 Add, Edit, Delete & View Student Records
- 📅 Attendance Management
- 📊 Dashboard with Student Information
- 🔍 Search Student Records
- 📱 Responsive User Interface
- 💾 SQLite Database Integration


## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS
- Bootstrap 5

## 🚀 Installation

 ### 1. Clone the repository

```bash
git clone https://github.com/pranavpatil278/EduTrack.git
```

### 2. Navigate to the project folder

```bash
cd EduTrack
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open your browser and visit 

```bash
http://127.0.0.1:5000
```

 ### 6. 🔑 Default Login

For demonstration purposes, use the default administrator credentials:

- **Username:** `admin`
- **Password:** `admin@123`
